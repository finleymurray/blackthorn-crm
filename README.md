# Blackthorn CRM

Guest, marketing and support platform for Blackthorn Scream Park (demo).

Built with Next.js, TypeScript, Supabase (Postgres, Auth, row level security),
Tailwind CSS and Recharts. No real emails, SMS or payments are ever sent: every
message lands in a demo outbox and refunds are simulated.

Setup instructions, demo logins and a suggested demo script are at the bottom
of this file once the build is complete.
